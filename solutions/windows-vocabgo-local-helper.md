## 遇到的问题

词达人学生入口在普通浏览器中显示“请在微信客户端打开链接”。本机 Edge 扩展已安装并启用，
但这并没有让该入口使用微信中的登录状态。本次客户端也未显示可用的通用桌面控制入口，
因此没有继续尝试接管微信窗口。这个观察仅描述本次环境，不代表该功能在其他环境中不可用。

改用本机源码方案后，需要解决两件实际问题：这台电脑没有可直接使用的 Python；
上游登录接入会设置系统代理、添加本地证书，且存在将完整登录凭证写入日志的代码。

## 本次改动

1. **独立部署。** Python、依赖和缓存留在项目目录，增加启动与恢复入口；记录依赖版本与源码提交。
2. **凭证保护。** 登录框隐藏凭证；移除完整凭证日志；注册凭证后对程序日志脱敏；结束时清理临时中转文件。
3. **限制接入范围。** 接入服务监听 `127.0.0.1`，HTTPS 检查范围限于 `app.vocabgo.com`，最多等待 3 分钟。
4. **恢复网络设置。** 修改前保存原代理值；正常结束、取消或超时后恢复；仅按精确指纹移除本次新增证书。异常退出时保留恢复记录并提供独立恢复入口。
5. **任务与稳定性。** 隐藏批量处理全部任务和第三方二进制凭证获取入口；保留逐项选择。增加网络请求超时、修正更新地址，并缓存语言模型。
6. **可复现发布。** 发布上游文件的补丁与本次新增文件，通过固定源码压缩包重建；调用当前 Python 启动接入模块，避免依赖另一台机器上的绝对路径启动器。

## 验证与边界

本机依赖兼容性检查通过，界面已打开；9 项离线检查覆盖日志脱敏、域名筛选、恢复顺序、
证书不匹配、恢复失败保留记录等路径。真实接入模块也能以本机临时端口启动；这个启动检查没有修改系统代理或信任库。
公开补丁包还使用本机已校验的下载缓存，从固定源码重建，并再次通过以上检查。

这些结果只证明环境与所检查的行为。真实账号授权、具体题型和两个班级任务的完成情况尚未确认。
没有将学生账号、登录凭证、临时证书、代理快照、学习记录、截图或日志上传到仓库。

## 重建与使用

按[工具包 README](../tools/vocabgo-local-helper/README.md)在 Windows 上运行 `setup.ps1`，
安装后从“启动词达人助手.cmd”打开。登录接入由使用者在本机确认并通过电脑版微信完成，
随后核对任务列表，逐项选择需要的任务。
