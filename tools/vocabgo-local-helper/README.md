# Easy_Cidaren 本机部署与改进补丁包

**基于 [ularch/Easy_Cidaren](https://github.com/ularch/Easy_Cidaren) 的二次改进案例。**
原项目负责词达人任务读取、自动作答与题型适配。本目录记录 NexD5701 在 AI 协助下完成的本机部署、凭证保护和异常恢复改动。
完整来源与署名见 [NOTICE.md](NOTICE.md)，许可证见 [LICENSE](LICENSE)。

**验证状态：** Windows 11 x64 上已准备独立 Python 环境、打开程序界面，并通过 9 项离线检查和本地接入服务启动检查。
尚未确认真实账号登录、具体班级任务完成或其他电脑上的完整安装。
发布包已使用本机校验过的下载缓存，从固定源码重新构建，并再次通过依赖检查、9 项离线检查和本地服务启动检查。

## 这里提供什么

- `upstream.patch`：对 8 个上游文件的明确差异，可逐行审阅。
- `files/`：新增的本机登录接入服务、启动脚本和网络恢复脚本。
- `tests/`：9 项离线检查，以及不修改系统代理或证书信任的接入服务启动检查。
- `setup.ps1`：下载固定版本源码、独立 Python 和 uv，校验压缩包后应用补丁、安装锁定依赖。
- `UPSTREAM.json`：上游提交、下载来源与 SHA-256。
- `requirements.lock.txt`：本次验证使用的依赖版本。

公开内容不包含使用者的登录凭证、临时证书、系统代理快照、日志、学习记录或安装缓存。

## 在 Windows 上重建

需要 64 位 Windows、Git，以及访问 GitHub、python.org 和 PyPI 的网络。
运行目录需要可写。Python 放在本目录 `.setup/python` 内，不注册到系统或修改全局 PATH。

在 PowerShell 中进入本目录后运行：

```powershell
.\setup.ps1
```

按本机或组织的 PowerShell 脚本策略处理执行权限；该脚本不会修改执行策略。
脚本会获取 `UPSTREAM.json` 中的压缩包并校验 SHA-256，应用补丁、安装依赖后执行离线检查。
下载的上游源码会包含上游公开发布的文件；本方案的界面隐藏了其第三方二进制凭证获取入口。

如果只想准备源码、应用补丁和解压独立 Python，可运行：

```powershell
.\setup.ps1 -PrepareOnly
```

安装完成后，双击本目录的 **启动词达人助手.cmd**。

## 登录接入与逐项操作

1. 首次打开的免费软件提示可以关闭。
2. 在助手中选择“帮助 → 获取 token → 内置”，再点“开始捕获”。
3. 阅读确认框：接入会临时设置当前用户的系统代理，临时信任本工具的本地证书；HTTPS 检查限于 `app.vocabgo.com`。
4. 同意后，在电脑版微信打开“词达人 → 学生端 → 班级任务”。接入最多等待 3 分钟。
5. 取得授权后，程序会尝试恢复原代理、移除本次新增的证书，再将凭证填入登录框。
6. 登录后核对任务名称、类型和进度，逐项选择需要的任务。批量处理全部任务的入口已隐藏。

接入可以取消。若进程意外退出，关闭助手后双击 **恢复网络设置.cmd**。
恢复程序只使用本工具保存的原代理快照和本次新增证书的精确指纹。
登录接入和真实任务仍需在使用者本机验证；离线检查不构成账号或题型兼容性保证。

## 离线验证

```powershell
.\.setup\python\python.exe .\tests\verify_local_setup.py
.\.setup\python\python.exe .\tests\check_listener.py
```

第一项检查界面、语言模型、日志脱敏、跨站忽略、恢复与失败路径；不会操作学生账号或修改真实代理、证书信任。
第二项只在本机临时端口启动接入服务，产生的测试证书不加入系统信任库。

## 范围与限制

- 登录凭证仅保存在本机进程和短期中转文件中；接入结束后清理中转文件。
- 正常退出、取消和超时会走恢复逻辑；强制结束进程或系统断电后，需要运行恢复入口。
- 运行期间用同一账号重新进入词达人，可能刷新凭证；参见上游说明。
- 这里记录的是已完成的工程改动，不宣称新增了上游原有的自动答题能力。
